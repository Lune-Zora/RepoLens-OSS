# RepoLens-OSS

面向 Python 开源贡献的 Issue 理解、源码定位、候选补丁与测试验证工作台，提供 CLI 和 Web。当前版本 **0.7.0**，更新于 **2026-10-30**。

## 快速开始

需要 Python 3.10 及以上、已启动的 Ollama 和本机可用模型。本机验证环境为 Python 3.10.11。进入解压后的项目根目录执行：

```powershell
python -m pip install -c constraints.txt -e '.[web,test]'
python scripts/start_web.py
```

工作台地址：`http://127.0.0.1:8000/`。当前默认模型为本机标签 **`qwen35-9b-unc:latest`**，页面可选择其他已安装模型。这是本机标签，其他电脑须安装有合法来源的模型并按实际标签配置；源码包不附带权重。

Ollama 的 `http://127.0.0.1:11434/v1` 是模型 API 根地址，不是网页；直接打开出现 404 不代表工作台故障。启动脚本读取环境变量、`.env` 与默认值，普通 CLI 不自动读取 `.env`。详细命令见[模型配置与启动](docs/06_运维/模型配置与启动.md)。

## 当前工作流程

1. 选择实际目标仓库，输入问题现象、复现输入和预期行为。模型先理解原始需求，再核对真实源码及公开接口，展示目标、检索表达和无法定位的原因。
2. 在补丁生成前设计、审核并冻结当前问题的行为用例。也可明确提供输入与期望；此类用例标记为调用者提供，不记作模型自动生成。
3. 运行真实测试确认问题能够复现，生成候选补丁，检查文件及函数修改范围，再运行原有测试和问题用例。
4. 仓库外独立验收在模型调用前冻结，不进入模型输入或候选重试反馈。结果分别展示材料核验、重放一致性和修复结论。
5. 下载报告和实际 diff，审阅后应用。**验证在临时副本中进行，不自动改写目标仓库原文件。**

当前启动默认采用严格模型模式，模型失败不会用规则补丁冒充成功。历史离线规则只覆盖少量模式。没有独立验收时，模型测试通过也不能据此标为 `VERIFIED`；重放 `PASS` 表示与记录一致，不会把失败结论变成成功。

## 目录

```text
replens/       问题理解、索引检索、计划补丁、测试验收与证据重放
web/           FastAPI API 与静态工作台
examples/      历史 Demo、独立构造任务及仓库外验收
tests/        项目自身测试
scripts/       启动、模型校验、独立任务验证、报告生成等工具
eval/          评测数据与参考补丁；参考答案不进入模型输入
docs/          技术报告、设计、接口、测试和运维文档
reports/       实验、历史模型证据与第三方资源核验
project-os/    当前状态、维护历史及本轮完整证据
```

索引缓存按源码及文档内容 SHA-256 判断更新，默认排除生成报告和任务测试目录。运行输出放在目标仓库的 `.replens/`；上传包排除缓存、实际 `.env`、模型权重、构建临时目录和大型浏览器调试轨迹。
