## 核心链路（修复后顺序）

1. 导入固定版本 Python 仓库（排除 .replens/.git/缓存等运行产物）
2. 先复现失败，提取执行轨迹（traceback 帧）
3. 轨迹 + Issue 检索（结构/文档索引），证据不足则拒答
4. 生成计划（规则演示 / LLM 严格模式，严格模式不回退规则）
5. 生成补丁（证据白名单 + 测试/配置保护 + 结构化校验）
6. 临时副本 before→after 测试（有效验证判定，缺依赖/零收集不误判成功）
7. 失败且有预算 → 上一轮补丁 + 失败日志反馈重试
8. 独立回归测试 + 报告 + 可复核证据包
