## 0. 作品基本信息
- 作品名称：RepoLens-OSS —— 面向开源贡献的新手 Issue 定位、补丁生成与验证工作台
- 申报方向：方向二（AI 开发工具与开源协作）为主，融合方向三（开源项目改进与生态贡献）
- 仓库链接 / 演示视频链接 / 团队成员与分工 / 指导教师

## 1. 问题背景与选题意义
- 新手做开源贡献的三道坎：看不懂代码结构、不知道改哪里、不敢保证改对。
- 现有 AI 编程工具（调研：SWE-agent、OpenHands、Aider、RepoAgent）偏向"通用智能体"，
  对新手不够透明、结果难以证伪、成本高。
- 本作品把问题收敛为：用"证据+测试"让每一次定位与修复都可验证。

## 2. 相关工作调研（务必附对比表）
| 工具/基准 | 定位方式 | 补丁方式 | 可验证性 | 依赖/成本 |
|---|---|---|---|---|
| SWE-bench / SWE-agent | LLM 自主循环 | LLM 改文件 | 测试通过率 | 需 LLM API |
| OpenHands | 智能体+工具 | 多步执行 | 测试 | 需 LLM API |
| RepoAgent | 对象图+LLM 文档 | 文档生成 | 人工 | 需 LLM API |
| Aider | 仓库地图+LLM | 对话式改码 | 测试 | 需 LLM API |
| RepoLens-OSS（本作品） | FTS5+调用图+向量 RRF，确定性为主 | 规则/LLM+结构化校验+测试反馈重试 | 证据+exit code 对比 | 核心零依赖，离线可跑 |

## 3. 系统设计与实现
- 3.1 总体架构图（接入层/应用层/索引层/生成执行层）
- 3.2 索引层：AST 符号提取 + SQLite FTS5 + 调用图（imports/calls 表）
- 3.3 检索定位层：BM25 关键字 + 语义向量 RRF 融合 + 证据不足拒答
- 3.4 计划与补丁层：RulePlanner（零 key 兜底）/ LLMPlanner；patchgen 自动补丁
  （JSON 补丁规则 + from 串必须真实存在的校验）
- 3.5 验证层：临时副本 + 命令白名单 + 超时 + 修复前后 exit code 对比
- 3.6 合规层：LICENSE 识别 + 第三方依赖披露报告
- 关键实现细节：Windows UTF-8 兼容、源码指纹索引复用、FTS5 降级 LIKE

## 4. 关键技术与创新点
- 证据优先、可证伪的定位与修复闭环（对照 P1 创新点清单）
- 确定性检索与语义检索的 RRF 融合（不牺牲零依赖兜底）
- 补丁生成的结构化校验与"测试反馈→修复重试"闭环
- 三层安全执行与原仓库不可变保证
- 离线零 key 可完整演示（规则引擎兜底）
