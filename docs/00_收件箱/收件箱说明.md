# 收件箱说明

> 本目录是**临时落点**，不是最终归档位置。任何文件在此停留不应超过一个会话。

## 什么时候放这里

| 场景 | 说明 |
|---|---|
| 脚本产物改不动 | 某些脚本硬编码输出英文名或根目录，无法改输出路径时，至少指到这里 |
| 分类信号不明 | 拿到一份文档但判不出该进哪个专题，先放这里并登记 |
| 外部导入材料 | 从对话/邮件/外部仓库拿到的待整理内容 |

## 处理规则

1. 放入即登记到[收纳记录](../99_进度/收纳记录.md)，写明来源与待判定原因。
2. 每个会话结束时必须清零：要么归类到 `docs/<NN_专题>/`，要么移入 `docs/07_归档/`，要么删除（需用户确认）。
3. 归类后按分类信号表重命名：

| 内容信号 | 目标目录 | 目标命名 |
|---|---|---|
| 需求、用户故事、PRD | `01_需求/` | `PRD-<中文功能名>.md` |
| 架构、设计、方案、决策 | `02_架构/`（决策类→`决策记录/`） | `DESIGN-<中文主题>.md` / `ADR-NNN-<中文决策名>.md` |
| 流程图、Mermaid | `02_架构/`（接口流程→`04_接口/`） | `流程图-<中文主题>.md` |
| 表、字段、ER、SQL | `03_数据库/` | `DB-<中文主题>.md` |
| 接口、API、endpoint | `04_接口/` | `API-<中文模块名>.md` |
| 测试、用例、覆盖率 | `05_测试/` | `TEST-<中文范围>.md` |
| 部署、运维、监控、回滚 | `06_运维/`（手册→`运维手册/`） | `RUNBOOK-<中文主题>.md` |
| 已废弃、旧版、历史 | `07_归档/` | 保持原名 |
| 进度、待办、日志、清单 | `99_进度/` | 固定中文名 |
