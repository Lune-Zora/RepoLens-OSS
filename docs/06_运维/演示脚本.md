# 0.7工作台演示步骤

本地工作台：http://127.0.0.1:8000/。先确认Ollama服务可用，选择qwen35-9b-unc:latest。视频要求仍按比赛文件核对；下面按约3—5分钟组织，真实执行耗时以本机为准。

1. 展示项目目标、当前仓库路径和所选模型，说明它修复的是这个仓库中的问题。
2. 选择一个明确标注的独立构造任务，或输入自己的仓库。构造任务源码没有修复提示，但不冒称外部真实Issue基准。
3. 输入中文问题。若提供明确的输入/期望，展示该样例并说明它是调用者给定的契约，不称为模型自动生成。
4. 执行完整闭环。等待真实返回后，展示问题理解、实际目标、冻结用例、修复前后逐测试结果和独立验收结果。
5. 展开diff，说明补丁由模型产生，测试在临时副本执行，原仓库没有被自动覆盖。
6. 点击重放证据包，展示材料核验、重放和修复三个结果；下载Markdown报告及实际补丁。
7. 展示本轮验收页中的其他任务记录，说明它们是已归档运行结果。模型生成测试仍会出错；没有独立验收不会获得VERIFIED，失败会保留原因。

当前版本支持模型选择、自由问题描述、任务用例生成/审核、调用者明确行为样例、原有测试保持、函数修改范围检查和独立重放。它不是任何复杂仓库都能一次自动修复的产品，演示结论限定在实际测试范围。

完整数据与失败记录见[通用修复流程验收](../05_测试/通用修复流程验收.md)。
