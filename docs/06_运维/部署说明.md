# 本地 Web 部署说明

本次已验证范围为本机环回地址运行。模型配置和启动命令以 [模型配置与启动](模型配置与启动.md) 为准。

## 网页地址与模型地址

网页：`http://127.0.0.1:8000/`；模型 API 根地址：`http://127.0.0.1:11434/v1`。浏览器直接打开后者可显示 404，它不提供工作台页面。模型列表检查为 GET `http://127.0.0.1:11434/v1/models`。

0.7默认模型为本机 `qwen35-9b-unc:latest`；早期归档Demo使用1.5B，记录保留。便捷启动命令 `python scripts/start_web.py` 会加载九项 LLM 配置并从正确目录启动；按下面标准 uvicorn 方式启动时仍须手动设置环境。

## 依赖和启动

在项目根目录、准备好的 Python 环境中：

```powershell
python -m pip install -c constraints.txt -e '.[web,test]'
python scripts/check_env.py --with-web
```

安装示例需联网或预备依赖，本次文档核对不等于新环境安装验收。
执行模型配置文档第 2 节的环境变量命令后，在同一个终端启动：

```powershell
python -m uvicorn web.app:app --host 127.0.0.1 --port 8000
```

浏览器打开 `http://127.0.0.1:8000`。修改模型配置后须重启服务。
`/api/env` 是配置展示，不是模型推理健康检查。

## 本地检查

- GET `/api/env`：检查服务进程是否继承了地址和模型配置。
- GET `/api/repos`、`/api/datasets`：检查可用仓库和评测材料。
- POST `/api/search`、`/api/plan`、`/api/run`：分别是定位、计划和完整修复入口。
- `/api/analyze` 不是当前实现的路由；旧部署文档中该路径已过时。
