## 来源与使用边界

上述模型标签是本机实际标识，不等于官方发布权重的来源认证。本机 GGUF 最初下载或转换来源仍待补充；资源清单保留待核验状态，源码包不分发模型权重。未运行可选训练脚本，也不宣称使用自有微调权重。

模型通过本地 HTTP 接口参与问题理解、任务用例设计/审核、计划与补丁生成；仍可能出错。接口连通或页面显示“已配置”不是推理成功证据。不能仅凭模型规模断言质量，也未验证任意第三方模型兼容性。
