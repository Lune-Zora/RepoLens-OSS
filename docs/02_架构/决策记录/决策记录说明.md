# 决策记录说明

> 本目录存放**架构决策记录（ADR）**：一次决策一个文件，只增不改，被推翻时写新 ADR 并把旧的标为 superseded。

## 与 project-os/决策日志.md 的分工

| 位置 | 记什么 | 粒度 |
|---|---|---|
| [project-os/决策日志.md](../../../project-os/决策日志.md) | **流水账**：所有规则/流程/目录变化，一行一条 | 一句话 |
| 本目录 ADR | **需要展开的架构决策**：背景、备选方案、取舍、后果 | 一篇一决策 |

> 判据：一句话能说清的进决策日志；需要解释「为什么不用另一个方案」的，写 ADR。

## 命名

`ADR-NNN-<中文决策名>.md`，NNN 三位数字从 001 起递增，不复用编号。

## 模板

```markdown
# ADR-NNN <中文决策名>

> 状态：提议中 / 已采纳 / 已被取代（取代者：ADR-XXX）
> 日期：YYYY-MM-DD

## 背景
为什么要做这个决策，当前遇到什么问题。

## 备选方案
| 方案 | 优点 | 缺点 |
|---|---|---|

## 决策
选了哪个，为什么。

## 后果
好的影响与代价，需要同步修改哪些地方。
```
