# RepoLens-OSS 规则说明

> 文件命名：docs/02_架构/规则说明.md（固定中文名）

## 1. 技术栈与版本
| 项 | 值 |
|---|---|
| 语言 | Python ≥3.10 |
| 框架 | 核心零第三方依赖（纯标准库）；Web 层 FastAPI + Uvicorn（可选 `[web]`） |
| 构建工具 | setuptools ≥61（pyproject.toml） |
| 关键依赖 | 核心无；可选 web：fastapi>=0.110、uvicorn>=0.29；LLM 层用标准库 urllib 接 OpenAI 兼容 API |

## 2. 目录结构与模块职责
| 目录/模块 | 职责 |
|---|---|
| replens/ | 核心包：repo（仓库导入）/ indexer（AST+SQLite FTS5 索引）/ retriever、retriever_hybrid（检索）/ planner / patchgen / testgen / executor / report / llm / compliance / cli |
| web/ | 可选 FastAPI Web 层（app.py 提供 search/plan/run 等端点，static/ 为 vanilla JS 前端） |
| eval/ | 脚本入口与 datasets/training/mined/reference_patches；用途见 eval/README.md |
| examples/demo_repo | 内置演示仓库（4 模块，含 5 处真实 bug 与修复补丁） |
| tests/ | replens 包自身单元测试（pytest 收集 unittest 用例） |
| scripts/ | 训练数据构建、微调评测、评测集准备脚本 |
| docs/ | 按专题组织的中文技术文档，入口为 docs/文档地图.md |
| reports/ | demos/experiments/compliance/archive 与后续 runs 输出，见 reports/README.md |

## 3. 编码规范
- 命名：Python 模块小写（replens、web、eval）；遵循 PEP 8 惯例。
- 格式：仓库未显式配置格式化工具；以 PEP 8 为默认。
- 注释：README 与模块 docstring 说明用途；核心原则「让模型的每一个判断都能被代码证据和测试结果证伪或证实」。
- 禁止事项：核心包 replens/ 引入第三方运行时依赖；弱化/删除失败测试。

## 4. 构建 / 测试 / 运行
| 命令 | 作用 |
|---|---|
| `python -m replens init <repo>` | 导入仓库（识别许可证/依赖/测试框架） |
| `python -m replens index <repo>` | 构建代码结构索引（AST + SQLite FTS5） |
| `python -m replens search <repo> --issue "..."` | 检索定位 + 证据 |
| `python -m replens plan <repo> --issue "..."` | 生成修改计划 |
| `python -m replens run <repo> --issue "..." --test-cmd "..." --auto-patch` | 完整闭环（定位→计划→自动补丁→测试验证→报告） |
| `python -m replens eval <repo> --dataset eval/datasets/dataset.json` | 跑评测集（hit@1/hit@5/func@5/line_acc/MRR/拒答率） |
| `python eval/baselines.py <repo> --dataset eval/datasets/dataset.json` | 基线对比（random/grep/BM25/混合） |
| `python -m replens compliance .` | 合规披露（第三方依赖与开源许可） |
| `python -m pytest tests/ -q` | 单元测试 |
| `pip install -e .[web] && uvicorn web.app:app --reload` | 启动 Web 可视化工作台（http://127.0.0.1:8000） |

## 5. 接口规范（如有）
- 风格：REST（FastAPI Web 层）。
- 主要端点：web/app.py 提供 search / plan / run 等端点（详见 docs/04_接口/）。
- 返回结构：以 web/app.py 实际实现及 docs/04_接口/API-Web工作台.md 为准。

## 6. 已知约束与风险
- 核心包 replens/ 必须保持零第三方依赖。
- 复杂 Issue 的根因分析与通用补丁需接入 LLM（OpenAI 兼容 API 或本地模型）。
- 混合检索需 REPLENS_EMBED_BASE_URL/KEY 或本地 fastembed。
- SQLite FTS5 依赖运行环境支持。
