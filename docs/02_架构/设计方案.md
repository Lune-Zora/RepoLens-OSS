# 当前实现设计说明

更新：2026-10-30。本页描述代码实际实现；旧设计快照保存在本轮事实校正的修改前文档中。

## 编排

CLI `cmd_run` 与Web `api_run`共用`runner.run_repair`。首先读取并冻结仓库外独立验收材料，建立索引，再复现失败、提取轨迹、检索、生成计划、生成候选、测试筛选、辅助回归、独立验收并打包。独立验收结果不用于候选生成反馈。

## 模块边界

- repo/indexer：Python与文档清单、AST、SQLite；索引复用基于mtime/大小元数据，不是源码内容认证。
- retriever/retriever_hybrid：关键词、调用关系、可选向量RRF；语义候选仍受关键词池和拒答门槛影响。
- execution_evidence/falsify：轨迹匹配和启发式加权，不是因果证伪或正确概率。
- planner/patchgen/llm：计划、有限规则、HTTP模型、结构化补丁、候选测试与重试；严格模式禁止规则补丁代替模型。
- executor/test_adapter/validation：临时副本测试、测试ID和有效性记录、原有PASS保持、冻结独立验收。临时目录不是系统沙箱。
- provenance/llm_audit：材料、源码哈希、重放和可选HTTP调用记录。不是不可篡改的第三方证明。
- miner/era_env：历史提交候选与定向测试、时代依赖环境；通过参考补丁测试不等于模型修复。

## 当前事实

[提交事实与证据](../05_测试/提交事实与证据.md)是数字来源。核心默认规则与HTTP客户端路径采用标准库；Web、测试及可选transformers/向量后端依赖另装。模型服务与权重不包含在“核心零第三方依赖”说法中。
普通CLI/Web不自动读.env，配置方法见[模型配置与启动](../06_运维/模型配置与启动.md)。

## 已知限制

同名符号仍主要采用短名，限定名评测单列为不支持；索引更新元数据存在局限。测试翻转字段在补丁测试后计算，不是预先冻结的预测。当前没有操作系统级权限隔离、已验收的公网部署或全新机器交付证明。
