# 设计特点与证据边界

更新：2026-10-30。本页不作首创或全面领先声明。

1. 代码证据约束：检索证据绑定文件、符号起始行和代码片段，供模型生成计划与补丁。
2. 测试反馈流程：候选结构校验、临时副本运行与失败反馈重试。
3. 验收分离：原有PASS保持，自动生成检查仅辅助，冻结独立材料单独验收。
4. 可复核交付：源码/测试/补丁材料与模型调用记录，标准CLI重放。
5. 数据构建：历史提交与参考补丁定向验证，作为评测候选来源，不计模型成功。

当前实际结果见[提交事实与证据](../05_测试/提交事实与证据.md)。本轮调用图消融无增益，未执行向量组；测试翻转统计在测试后计算，不作为事前反事实预测。临时副本、命令限制和超时不是系统沙箱。哈希校验不是不可篡改认证。
