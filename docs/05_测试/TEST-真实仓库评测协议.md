# TEST-真实仓库评测协议

> 依据：审查报告第 10 节。定位实验、补丁验证实验、自主修复实验必须分开计数。

2026-10-20 更新：定位指标、冻结清单 v1 及可运行命令以 [评测口径与输入隔离.md](评测口径与输入隔离.md) 为准。旧版仅检查字段名的 manifest 不能作为隔离验收依据。

## 1. 三种实验

| 实验 | 输入 | 输出 | 是否计入模型修复 |
|---|---|---|---|
| 定位实验 | Issue + buggy 源码 | top-k、MRR、拒答 | 否 |
| 补丁验证实验 | 人工或上游已知补丁 | before/after | 否（只证明执行器与样本有效） |
| 自主修复实验 | 指定模型自行产生候选 | 独立测试结果 | 是 |

## 2. 每个样本必须留下

| 字段 | 内容 |
|---|---|
| sample_id | 唯一 ID，同一修复的不同描述不重复计数 |
| repository/source/license | 上游来源与该版本许可 |
| buggy_commit、fix_commit | 精确提交 |
| issue_source、issue | 原 Issue、提交或人工整理，注明是否改写；冻结实际查询文本 |
| environment | OS、Python、依赖锁定、安装命令 |
| regression_test | 明确输入与预期，及测试资源来源 |
| before_gold_validation | buggy 状态失败，参考修复后通过；未执行明确记录 pending |
| model_input_manifest | v1 schema：root、文件 path/kind/sha256；实际输入根只能包含允许文件 |
| reference_materials | 控制端参考补丁、标注、独立测试等实际文件的路径、角色和哈希，放在输入根之外 |
| candidate_trace | 模型来源、请求/候选/轮次、校验、耗时、失败类型 |
| independent_test_result | 冻结保留测试及原有回归结果 |
| replay_artifacts | 补丁、源码/环境指纹、日志、测试 ID、重放说明 |

## 3. 执行 7 步

1. 准备历史环境：获取上游 Git 历史，创建 buggy 提交独立工作区，锁定依赖。
2. 确认样本真实：先只加测试，buggy 代码应失败；再用参考生产补丁应通过。缺依赖/导入失败/资源缺失不算有效复现。
3. 隔离参考答案：gold diff、expected 标签、训练材料放在评测控制端，整理清洁输入根；运行清单校验及实际允许材料打包，再用严格评测入口从包建索引。检查允许材料自身是否暗含答案；路径/哈希校验不证明语义清洁。
4. 冻结配置：模型/权重、提示词、检索参数、预算、超时；留出集不反复调参；公开 Bug 可能被预训练见过，必须披露。
5. 运行所有尝试：记录成功、无效补丁、测试失败、拒答、超时、服务错误；失败补丁不得残留到下一候选。
6. 独立验收：候选通过公开测试后，运行冻结独立回归与原有测试；确认未改保护文件、测试收集未被规避。
7. 汇总与重放：至少重放一个成功和一个失败案例；环境错误单列；预先定义有效样本分母。

## 4. 公平对照

- 定位：random / grep / BM25 / BM25+轨迹 / 混合检索，同一源码与文档集合、同 top-k、同标注、同候选预算；文件先去重；所有 MRR 在同一 k 截断。逐 Bug 轨迹与真实语义模式需独立验证，尚未执行的配置不写效果结论。
- 修复（同一模型）：A 关键词检索+模型候选；B A+失败轨迹；C B+语义检索；D 完整受限反馈与测试筛选。
- 各配置同模型、同预算、同上下文与时间上限；独立测试评价候选；模型自写测试不能当唯一裁判。

## 5. 指标

- 定位：动态 `hit@1` / `hit@k`、`func_name@k`、`symbol_start@k`、截断 `mrr@k`、干扰拒答与正向误拒。函数仅比较同路径短名，行号为同一函数起始行 ±3；限定名暂不支持且单列。文件/MRR 分母为全部正向样本，函数/行分别为受支持标注样本。具体定义及旧别名迁移见新协议。
- 修复：独立测试验证的成功数 / 有效 Bug 数（规则、人工补丁、模型自主补丁分别计数）。
- 保持性：原本通过测试仍通过、收集/跳过变化。
- 失败：环境错误、格式/范围错误、行为错误、超时分别计数并给代表案例。
- 资源：总耗时、请求数、候选数、服务/硬件。
- 小样本：给原始分子分母；10 个样本单例影响 10 个百分点，不据此保证一般效果。
