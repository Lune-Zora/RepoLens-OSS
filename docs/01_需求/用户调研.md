# 用户调研：开源新手贡献痛点问卷

> 用途：为技术报告「1.1 背景与问题」提供需求真实性的可核验证据。
> 目标样本：开源新手贡献者（在校学生 / 初级开发者 / 首次提交 PR 者），N ≥ 10。
> 数据只用于需求论证，不收集个人身份信息（姓名、学校等敏感信息一律不采集）。

## 一、问卷（在线表单 / 访谈提纲）

### 背景（匿名，不采集身份）
1. 你的身份：□ 在校学生　□ 1-3 年开发者　□ 其他
2. 你是否向开源项目提交过代码（PR）？
   - □ 从未　□ 1-2 次　□ 3 次以上
3. 你常用的编程语言：____

### 痛点（核心，用于论证）
4. 首次面对一个陌生的开源仓库时，最困扰你的是？（可多选）
   - □ 看不懂代码结构，不知道 Issue 该改哪里
   - □ 找到了位置，但不敢确定改得对不对
   - □ 不知道怎么验证修改没有破坏其他功能
   - □ 不知道如何写测试 / 证明修复有效
   - □ 担心许可证 / 合规问题
5. 上述痛点中，哪一个是你**最大**的障碍？（单选）
6. 你在定位一个 bug 时通常怎么做？
   - □ 全库 grep 关键词　□ 靠 IDE 跳转　□ 问 AI（Copilot/ChatGPT）　□ 其他
7. 你会因为"不敢确定自己改对了"而放弃一次开源贡献吗？
   - □ 经常会　□ 偶尔会　□ 不会

### 方案接受度（用于验证作品价值）
8. 如果一个工具能给你"每个结论都带 文件:行号 证据 + 修复前后测试 exit code 对比"，你的信心会提升多少？
   - □ 显著提升　□ 有所提升　□ 不确定
