概览

面向开源贡献的新手 Issue 定位、补丁生成与验证工作台 —— 每一个判断都能被代码证据与测试结果证伪或证实。

先选择实际仓库，再描述该仓库中的问题。模型生成的测试属于辅助验证；独立验收需要另外提供，VERIFIED仅针对展示的测试范围。

仓库元信息

快速开始

① 定位 / 计划输入 Issue 描述，检索相关代码证据并生成修改计划。
② 完整闭环定位 → 计划 → 自动补丁 → 测试验证 → 报告，一键跑通。
③ 评测对标注数据集计算 hit@k / MRR / 拒答率等指标。
④ 合规披露生成第三方依赖与开源许可披露报告。

提供明确的输入与期望结果（可选，可用于纠正模型提出的测试）

单个目标函数可省略path和symbol。你提供的预期会原样冻结，模型不会修改；这些样例不能替代独立验收。

评测

文件先去重，hit 与 MRR 按同一 Top-K 截断；函数比较短名，行号比较同一函数的起始行。结果显示各粒度分母。

合规披露
