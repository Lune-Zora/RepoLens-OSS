## 结论

**requests 贡献 0 条样本，分母保持 104 不变。**

依赖不是障碍；真正的障碍是：

1. 历史提交的测试代码依赖 urllib3 1.x API，单一环境无法跨时代验证；
2. requests 的 fix 提交很少同时改源码与测试（抽样 11%），候选本就稀少；
3. miner 在纯插入 hunk 上会把插入点归属到前一个符号，导致标注偏差。
