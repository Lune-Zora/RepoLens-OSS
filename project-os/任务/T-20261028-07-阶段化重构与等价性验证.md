## 目标

把 `pipeline.run()` 从 256 行按 8 个阶段边界拆为阶段函数；并用真实流程对照证明重构等价。

## 前置检索结论（复用优先）

| 检索项 | 结论 |
|---|---|
| `run()` 是否有阶段边界 | **有**，`record['stage']` 共 8 处（此前误判为「无标记」，见 ADR-006 更正） |
| 既有测试能否兜底 | **不能**。11 条测试只覆盖 helper 与 preflight 失败路径，主流程未被执行 |
| 是否有可用上游克隆 | 有 `tqdm\`（commit 齐全、工作区干净、remote 与记录一致）→ **复用为对照环境** |
| 等价性验证工具 | 无 → 新建一次性归一化比对脚本（用完即删） |

## 执行要点

1. 引入 `_Context` 承载共享状态，`run()` 只做编排。
2. 拆为 9 个 `_stage_*`：preflight / upstream-verification / environment / independent-acceptance /
   buggy-worktree / buggy-baseline / gold-validation / cross-worktree-replay / complete。
3. 单变量对照：只替换 `pipeline.py`，其余不动，各跑一次完整流程。
4. 内容级归一化后比对 92 个产物，并测「同一代码跑两次」的固有方差。
