# 任务 T-20261007-09：证据包可信化

> 文件命名：project-os/任务/T-20261007-09-证据包可信化.md

## 需求（做什么 / 为什么）
- 背景：审查报告 6.9：证据包被描述为不可篡改贡献证明，但清单与文件同目录可共同编辑，verify 判据弱。
- 目标：改称「可复核运行证据包」；绑定 commit、源码树哈希、环境、命令、测试 ID；缺失即失败。
- 不做（范围外）：不承诺哈希证明原创；不做签名发布（后续可选）。

## 实现思路
- 方案：provenance.build_provenance 记录 repo commit、python 版本、命令、测试 ID 清单与文件哈希；verify_provenance 对缺失文件、命令不同、测试数不同明确失败。
- 备选方案与否决原因：保持最小改动，优先修复行为缺陷，不重写模块。
- 关键假设：核心包 replens/ 保持零第三方依赖；当前解释器可跑 unittest。

## 验收标准（怎么算完成）
- [ ] 验收点：源码不一致、缺文件、命令不同、测试数不同、局部修改均得到明确状态。
- [ ] 验证命令：python -m replens run ... && python -m replens verify ...
- [ ] 证据：project-os/证据/T-20261007-09-证据包可信化/
