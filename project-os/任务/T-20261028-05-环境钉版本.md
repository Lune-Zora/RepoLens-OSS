> 状态：accepted

## 目标

消除 `anyio` × `typing_extensions` 版本错配，让 3 条 HTTP 集成测试转绿、`web/` 可实测，并把约束固化进仓库防止复发。

## 根本原因（实测确认，非推测）

| 证据 | 内容 |
|---|---|
| `importlib.metadata.requires('anyio')` | `typing_extensions>=4.16.0; python_version < "3.15"` |
| 故障时已装版本 | `typing_extensions==4.11.0` |
| 直接验证 | `hasattr(typing_extensions, 'sentinel')` → `False`（仅有 `_Sentinel`） |
| 链条 | anyio 4.15.1 → 需要 te≥4.16 → te 4.11 无 sentinel → `anyio._core._typedattr` 导入失败 → `fastapi` 导入失败 → `web/` 不可用 + 3 条 HTTP 用例失败 |

> 关键：`anyio` 的元数据**已正确声明**该依赖，是环境实际安装版本不满足。属于环境漂移，不是 anyio 的缺陷。

## 前置检索结论（复用优先）

| 检索项 | 结论 |
|---|---|
| `pyproject.toml` 现有 web extra | 仅声明 `fastapi>=0.110`、`uvicorn>=0.29`，**漏掉 anyio/typing_extensions 传递约束** → 改造 |
| 是否已有 constraints 文件 | 无 → 新建 |
| 是否已有环境自检 | 无 → 新建 |
| 现有测试组织方式 | `unittest.TestCase` 风格（见 `tests/test_core.py`）→ **复用**同一风格 |
