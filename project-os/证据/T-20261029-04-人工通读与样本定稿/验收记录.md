机械复核验的是**事实**，验不了**语义**。这条样本完全通过 6 项机械检查，却根本不能用：

```text
Merge pull requests #1717 and #1767 (fixes #1658)
```

提交存在、父子正确、标注被改动触及、测试在补丁里——但它不是一条 issue 描述。

### 重复检测的做法

不是比标题相似度，而是比 **Git tree 哈希**：两个 `fix_commit` 不同但内容相同时也能抓到。
这条是本次唯一通过内容比对才发现的重复。

## 四、判定如何被执行

判定落成数据文件 `eval/datasets/人工复核判定.json`，按 `fix_commit` 记录（id 会随裁剪变化，哈希不会）。
`scripts/promote_mined.py` 读取该文件，`verdict=exclude` 的提交直接跳过并在输出中列出理由：

```text
人工判定剔除: 4 条
  x [tqdm] 3757d0d13e 合并提交标题…
  x [loguru] 764cd30d4b 「Trivial grammar fix」只改了报错文案…
  x [loguru] dcf42d9625 「Enable RET linting rule…」是启用 lint 规则后的代码风格调整…
  x [loguru] 4c8ebe267b 与 565a6f63bb 完全重复…
```

这样判定可复核、可推翻、可重放，而不是散落在会话里。
