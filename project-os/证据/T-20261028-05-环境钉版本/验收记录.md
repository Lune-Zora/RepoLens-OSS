> 验收时间：2026-10-28。结构化数据见[验证结果](验证结果.json)。

## 结论

困扰项目 3 次的 `anyio` × `typing_extensions` 冲突已定位根因并修复；3 条 HTTP 集成测试转绿，`web/` 首次可实测；约束已固化进仓库，故障未来会在 CI 第一步暴露。

## 根本原因（证据链）

| 步骤 | 实测证据 |
|---|---|
| 1 | `typing_extensions==4.11.0`，`hasattr(te, 'sentinel')` → **False**（只有 `_Sentinel`） |
| 2 | `importlib.metadata.requires('anyio')` → `typing_extensions>=4.16.0; python_version < "3.15"` |
| 3 | `anyio/_core/_typedattr.py` 第 10 行 `from typing_extensions import sentinel` → ImportError |
| 4 | `fastapi` → `anyio.abc` → 报错，FastAPI 不可导入 |
| 5 | `web/` 不可用；`test_eval` / `test_provenance` / `test_validation` 各 1 条 HTTP 用例失败 |

> anyio 的元数据声明**是正确的**，问题在于环境实际安装版本不满足声明。属于环境漂移，不是 anyio 缺陷。

## 修复动作

```bash
python -m pip install --upgrade 'typing_extensions>=4.16.0'
# 结果：4.11.0 → 4.16.0，sentinel 存在
```
